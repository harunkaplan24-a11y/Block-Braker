# 10x10 Blok Patlatma Oyunu

Sürükle-bırak mekanizmasına sahip, Web Audio API ses efektli ve Canvas tabanlı kıvılcım (partikül) patlama animasyonlu 10x10 Blok Bulmaca Oyunu.

## 🚀 Özellikler

- **10x10 Oyun Tahtası:** Tamamlanan satır veya sütunlar patlayarak temizlenir.
- **Ses Efektleri:** Web Audio API kullanılarak üretilen dinamik blok koyma ve lazer/gürültü patlama sesleri (Harici MP3/WAV gerektirmez).
- **Kıvılcım & Partikül Efektleri:** HTML5 Canvas üzerinde patlayan blok rengine özel kıvılcım animasyonu.
- **Sürükle & Bırak (Drag & Drop):** Hem masaüstü fare hem de mobil dokunmatik ekran tam desteği.
- **Rastgele Blok Üretimi:** Her turda 3 farklı blok şekli sunulur.
- **Skor ve Combo Sistemi:** Aynı anda birden fazla satır/sütun temizlendiğinde çarpan bonusu ve yükselen tonlu patlama sesleri.

## 💻 Çalıştırma

Projede harici hiçbir kütüphane veya bağımlılık bulunmamaktadır. 
`index.html` dosyasını tarayıcınızda (Chrome, Edge, Firefox, Safari vb.) doğrudan açarak oynayabilirsiniz.

## 🌐 GitHub Pages İle Yayınlama

1. Bu depoyu GitHub üzerinde oluşturun.
2. Kodları depoya yükleyin.
3. Reponuzun **Settings > Pages** sekmesine gidin.
4. Source kısmını **Deploy from a branch** yapıp branch'i `main` veya `master` seçin.
5. Birkaç saniye içinde oyununuz canlı web sitenizde yayınlanacaktır!
